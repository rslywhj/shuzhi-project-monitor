## 1. 系统用途

平台面向几十个统建项目，使用统一节点口径管理各项目独立计划，并实现：

1. 管理层查看项目组合态势、红黄绿分布和跨周期变化；
2. 项目经理按周更新节点、预测日期、风险和纠偏措施；
3. PMO统一管理项目、节点模板、基线、预警规则和周度快照；
4. 系统管理员维护账号、角色、密码策略、通知渠道和操作审计。

### 1.1 红黄绿状态

| 状态 | 图形/文字 | 含义 | 建议动作 |
|---|---|---|---|
| 绿 | ● 正常 | 当前计划受控 | 按计划推进并持续更新 |
| 黄 | ▲ 预警 | 已出现预测偏差或轻度延期 | 提前干预，明确恢复措施 |
| 红 | ■ 严重 | 已严重延期、逾期未完成或触发一票否决 | 升级处置并跟踪闭环 |
| 灰 | — 不适用 | 项目不使用该标准节点 | 不进入项目进度计算 |

系统同时展示颜色、图形和文字，不能只凭颜色判断。

### 1.2 数据口径

- **管理大屏**：默认使用最新已锁定周度快照，适合管理会议和正式汇报。
- **桌面工作台**：展示当前业务数据，适合日常维护和锁数前核验。
- **原始基线**：项目创建时冻结，永久保留。
- **当前批准基线**：最新经PMO批准的版本，是红黄绿判定的主要口径。
- **计划日期**：按业务日历日期展示，不因用户终端时区改变。
- **操作时间、通知时间、锁定时间和审计时间**：统一转换为 UTC+8 显示。

## 3. 所有角色通用操作

### 3.1 登录与退出

1. 打开系统地址。
2. 输入管理员分配的登录邮箱和密码。
3. 单击 **“登录工作台”**。
4. 登录后，右上角显示姓名和角色。
5. 退出时，单击右上角头像，选择 **“退出登录”**。

无法登录时：

- 检查邮箱是否填写完整；
- 检查大小写、输入法和密码；
- 联系系统管理员确认账号是否启用；
- 忘记密码时，由系统管理员执行密码重置。

### 3.2 修改个人密码

1. 单击右上角头像；
2. 选择 **“修改密码”**；
3. 输入当前密码；
4. 按页面展示的当前复杂度策略输入新密码；
5. 再次输入新密码并提交；
6. 修改成功后系统自动退出，使用新密码重新登录。

注意：

- 新密码必须满足系统管理员配置的长度和字符类别要求；
- 两次新密码必须一致；
- 密码最长128位；
- 修改后原会话失效。

### 3.3 使用通知中心

1. 单击右上角通知图标；
2. 查看周报催报、红灯升级、基线审批结果等消息；
3. 单击消息可标记为已读并跳转到对应业务页面；
4. 可使用 **“全部已读”** 批量处理未读消息。

### 3.4 常用导航

| 菜单 | 主要用途 |
|---|---|
| 项目总览 | 项目清单、节点热力矩阵、搜索和筛选 |
| 组合分析 | 组织/类型/负责人分析、延期预测、节点瓶颈、基线漂移 |
| 资源计划 | 资源容量、超配冲突和资源分配台账 |
| 项目台账 | 单项目节点、周报、风险、基线和审计 |
| 周度填报 | 更新本周进度、节点、原因、措施和附件 |
| PMO管理 | 快照、基线审批、节点模板和预警规则 |
| 打开管理大屏 | 默认进入深色“项目里程碑时间轴”，并可切换节点矩阵 |

## 4. 管理层使用手册

### 4.1 角色目标

管理层以只读方式掌握总体态势、识别需升级处置的项目，并查看锁定快照下的趋势和事后度量。

### 4.2 查看管理大屏

1. 从工作台左下角单击 **“打开管理大屏”**；
2. 系统默认进入 **“项目里程碑时间轴”**，纵向为项目、横向为动态6个月；
3. 默认月份范围为 **上月、当前月、未来4个月**。进入新月份后系统自动滚动，当前月份使用高亮列展示；
4. 时间轴展示全部在建项目，以及当前时间窗口内仍有实际完成节点的已结项项目；归档项目、完全没有可展示节点的空白行不进入大屏；
5. 查看顶部当月指标：
   - 本月计划到期；
   - 本月已完成；
   - 本月预测完成；
   - 截至快照锁定日逾期未完成；
   - 每项指标下方同时显示关键节点数量。
6. 单击指标卡片，时间轴只保留命中项目并高亮相应节点；再次单击同一指标可取消联动；
7. 在时间轴按组织、负责人、项目类型或健康状态筛选；
8. 单击节点标签或“+N”，查看：
   - 计划完成日期；
   - 预测完成日期和实际完成日期；
   - 节点完成度、权重和关键节点标识；
   - 相对基线偏差；
   - 偏差原因。
9. 在详情抽屉单击 **“进入项目详情”**，查看完整项目台账。

### 4.2.1 时间轴图例与月份移动

时间轴节点同时使用文字、形状和颜色表达口径：

| 标记 | 含义 |
|---|---|
| ◇ 计 | 当前批准基线的计划完成月 |
| ● 实 | 节点实际完成月 |
| ▲ 预 | 未完成节点的预测完成月 |
| ■ 逾 | 截至快照锁定日已经逾期且尚未完成 |
| 计/实、计/预 | 计划与实际或预测落在同一个月，合并展示 |
| 逾·计、逾·预、逾·计/预 | 节点已经逾期，并同时保留对应的计划或预测口径 |
| 关 | 关键节点 |

一个项目在同一个月最多直接显示两个节点，其余节点聚合为“+N”。计划完成月早于当前时间窗口的逾期节点，会作为“逾”标记带入当前月，避免历史欠项从主视图消失。

月份导航操作如下：

1. 单击月份范围两侧的“‹”或“›”，整体向前或向后移动一个月；
2. 单击 **“回到本月”**，恢复“上月、当前月、未来4个月”；
3. 手动移动月份仅改变查看窗口，不修改里程碑数据；
4. 单击顶部任一当月指标时，系统自动回到本月窗口。

### 4.2.2 全屏查看和配置翻页

在时间轴或节点矩阵底部均可直接设置：

1. **每页行数**：输入1至50之间的整数，按 Enter 或移出输入框后生效；超出范围时系统自动修正为1或50；
2. **全屏时间轴/全屏矩阵**：仅放大当前主体区域；单击“退出全屏”或按 Esc 返回大屏；
3. **自动翻页**：通过开关启用或暂停自动翻页；
4. **翻页间隔**：自动翻页启用时，可选择5、10、15、20、30或60秒；
5. **手动翻页**：单击“‹”或“›”切换上一页、下一页；
6. 页码以“当前页 / 总页数”展示，只有一页时手动翻页按钮自动禁用。

每页行数和自动翻页配置保存在当前浏览器，同一台大屏终端下次打开时继续使用，不改变其他用户或其他终端的设置。打开节点详情抽屉时自动翻页临时暂停，关闭后恢复。

移动端进入时间轴时，项目列固定在左侧，月份区域可横向滑动并自动定位当前月；右上角“进入工作台”按钮保持可见，详情抽屉使用全屏宽度。

### 4.2.3 导出大屏 PDF

时间轴和节点矩阵右上角均提供 **“导出 PDF”**：

1. 系统导出当前筛选条件下的全部匹配项目，不受屏幕当前页限制；
2. 报表固定采用 A4 横向版式，超出项目行自动分页；
3. 每页重复标题、快照周期、筛选条件、列头、图例和页码；
4. 时间轴每页最多10个项目，节点矩阵每页最多8个项目；
5. 单击后在浏览器打印窗口选择“另存为 PDF”；如当前处于全屏模式，系统先退出全屏再打开打印窗口；
6. 报表继续使用文字、形状和颜色共同表达红黄绿状态，适合会议材料归档。

### 4.2.4 切换项目节点矩阵

1. 在时间轴右上角单击 **“节点矩阵”**，进入原有“项目 × 标准节点”热力矩阵；
2. 节点矩阵继续展示项目总数、红黄绿项目数、总体进度、周报完成率、重点异常和近12周趋势；
3. 单击矩阵右上角 **“时间轴”** 返回主大屏；
4. 从工作台重新打开管理大屏时，始终默认进入里程碑时间轴，不记忆上一次切换结果。

### 4.3 查看重点异常

优先检查以下内容：

1. 红色项目和关键节点红色；
2. 高概率预测延期项目；
3. 开放高风险和逾期措施；
4. 未来7日到期节点；
5. 资源利用率超过100%的冲突；
6. 连续多个周期红灯或新转红项目。

### 4.4 查看组合分析和事后度量

1. 进入 **“组合分析”**；
2. 按组织、项目类型、负责人、状态进行筛选；
3. 查看健康分布、平均得分、进度落后和基线漂移；
4. 查看“标准节点瓶颈排行”和延期预测解释；
5. 选择12、24或52周观察窗口，查看：
   - 新转红；
   - 恢复正常；
   - 持续红灯；
   - 状态波动；
   - 持续性节点瓶颈。
6. 使用 **“导出分析报表”** 或 **“导出历史明细”** 下载材料。

### 4.5 管理会议建议流程

1. 确认大屏快照周期和版本；
2. 按红色项目排序逐项查看；
3. 检查节点偏差、风险、措施和资源冲突；
4. 进入项目详情核对健康度扣分和一票否决原因；
5. 明确责任人、恢复日期和下次检查点；
6. 会后由项目经理或PMO在风险与措施中留痕。

## 5. 项目经理使用手册

### 5.1 角色目标

项目经理负责本人项目的主数据、节点进度、风险措施、资源计划和周报，确保每周五17:00前完成正式提交。

### 5.2 推荐周度工作节奏

| 时间 | 建议动作 |
|---|---|
| 周一至周二 | 更新风险、措施和资源需求 |
| 周三 | 根据催报通知检查本周节点和预测日期 |
| 周四 | 保存周报草稿，补充附件和偏差原因 |
| 周五17:00前 | 正式提交周报并确认无必填项遗漏 |
| 锁数后 | 查看快照结果；确需修订时联系PMO重新打开 |

### 5.3 查看和维护本人项目

1. 进入 **“项目总览”**；
2. 搜索项目名称，或按生命周期、健康状态筛选；
3. 单击项目进入详情；
4. 查看健康度、进度偏差、节点灯色和扣分解释；
5. 单击 **“编辑信息”** 可维护：
   - 项目名称；
   - 所属组织；
   - 项目类型；
   - 项目风险等级。

项目经理不能自行调整项目负责人，也不能在“编辑信息”中直接修改计划日期。

### 5.4 填报周度进度

入口：**项目详情 → 更新本周进度**，或左侧 **“周度填报”**。

#### 第一步：确认总体进度

1. 查看系统按节点权重计算的进度；
2. 调整“项目经理申报进度”；
3. 申报值与系统值相差超过5个百分点时，系统提示核验；
4. 正式提交必须填写本周进展或差异原因。

#### 第二步：更新节点

1. 选择本周发生变化或需要重点关注的适用节点；
2. 填写节点完成度；
3. 未完成节点填写预测完成日期；
4. 完成度为100%时填写实际完成日期；
5. 查看系统计算的相对批准基线偏差和预览灯色；
6. 填写本周进展、偏差根因、影响和判断依据。

#### 第三步：填写异常纠偏措施

节点被判为黄色或红色时，必须完整填写：

- 措施名称；
- 责任人；
- 预计恢复日期；
- 具体行动、资源投入、检查频率和完成标准。

#### 第四步：上传附件

- 单个文件不超过10MB；
- 支持 PDF、Word、Excel、PowerPoint、PNG/JPG、TXT、CSV、ZIP；
- 可上传会议纪要、验收材料、进度截图或问题清单；
- 本周期锁定后附件不可删除或替换。

#### 第五步：保存或提交

- **保存草稿**：允许稍后继续编辑，草稿保存在服务端；
- **提交本周进度**：执行正式必填校验并进入待锁定数据；
- 快照锁定后，本周期不可再修改。

### 5.5 填报双周滚动计划

入口：左侧 **“双周计划”**，或 **“项目详情 → 双周计划”**。

1. 选择本人负责的项目；PMO和管理员可选择任一在建项目，管理层只读查看；
2. 页面统一分为“本周计划及完成情况”和“下周计划及完成情况”，日期按 UTC+8 自然周（周一至周日）计算，不再拆分当前双周和历史计划两个入口；
3. 新增任务时填写任务描述、负责人、相关参加人员、计划开始/结束时间和周期（工作日）；
4. 执行过程中持续更新实际结束时间、完成状况、跟踪情况和备注；
5. 完成状况包括未开始、进行中、已完成、延期和已取消；选择“已完成”时必须填写实际结束时间；
6. 计划日期必须落在所选周内。进入新的一周后，窗口自动滚动为新的“本周＋下周”，历史任务仍保存在数据库和审计记录中；
7. 在“起始周”中选择当前或任一历史 ISO 周，即可查看以该周为“本周”、下一周为“下周”的滚动窗口；使用“更早／更新”按钮可连续翻周；当前周期可按权限维护，历史周期只读；
8. 统一视图支持按项目切换和 **“导出全量计划”**，一次导出当前项目全部历史、当前及未来周期的任务明细，不受当前所选起始周限制；没有计划数据时页面会给出明确空状态；
9. 已结项或已归档项目只读，需恢复为在建后才能继续维护；
10. 移动端自动将宽表切换为任务卡片，周期选择和翻周按钮也会改为适合窄屏的布局。

### 5.6 管理风险和纠偏措施

入口：**项目详情 → 风险与措施**。

登记风险时填写：

- 风险标题；
- 类别：进度、资源、质量、供应商或范围；
- 等级：低、中、高；
- 责任人和计划关闭日期；
- 风险描述和应对策略。

新建措施时填写：

- 关联风险（可不关联）；
- 措施名称；
- 责任人；
- 预计恢复日期；
- 具体行动。

后续应及时将风险更新为“已关闭”，并将措施更新为“待启动、进行中、已完成或已逾期”。

### 5.7 申请基线变更

仅在当前计划无法通过日常纠偏消化时申请：

1. 进入 **“项目详情 → 节点计划”**；
2. 单击 **“申请基线变更”**；
3. 选择需要调整的节点；
4. 填写新计划完成日；
5. 变更原因至少10个字符；
6. 填写对工期、成本、范围、资源和年度目标的影响；
7. 提交PMO审批。

审批完成前，当前批准基线不变。审批结果通过通知中心反馈。

### 5.8 项目级节点治理

入口：**项目详情 → 节点计划 → 节点治理**。

项目经理可在本人项目中：

- 调整节点顺序、权重、关键标识和适用性；
- 将不适用节点标记为灰色；
- 新增项目自定义节点。

注意：

1. 适用节点权重合计必须为100%；
2. 新增自定义节点默认权重为0；
3. 修改节点计划完成日期仍须申请基线变更；
4. 自定义节点默认不进入全局矩阵。

### 5.9 提交资源分配计划

1. 进入 **“资源计划”**；
2. 单击 **“新增分配”**；
3. 只能选择本人负责的项目；
4. 选择资源、项目节点、承担角色、起止日期和每周工时；
5. 执行容量预检；
6. 存在超配时，根据提示调整时间或工时；
7. 保存为计划分配，等待PMO确认。

项目经理只能编辑或取消尚未确认的本人项目分配。

## 6. PMO使用手册

### 6.1 角色目标

PMO负责项目组合口径、填报质量、基线审批、规则版本、资源冲突和快照锁定，保证管理层看到的数据一致、完整、可追溯。

### 6.2 新建项目

入口：**项目总览 → 新建项目**。

1. 填写项目编码、名称、组织、类型和风险等级；
2. 从已启用的“项目经理”账号中选择负责人；
3. 设置项目总体计划开始和完成日期；
4. 检查系统自动编排的标准节点日期；
5. 可逐节点校准计划开始、计划完成日期；
6. 确认启用节点权重合计为100%；
7. 单击 **“创建项目并冻结原始基线”**。

### 6.3 Excel批量导入

入口：**项目总览 → 下载导入模板 / Excel批量导入**。

1. 下载最新版模板；
2. 按“项目清单、节点计划、项目经理账号”三个工作表填写；
3. 每个项目编码必须唯一；
4. 负责人必须来自模板中的已启用项目经理账号；
5. 选择 `.xlsx` 文件，文件最大10MB；
6. 系统先在浏览器解析，再执行服务端逐行预检；
7. 修正全部错误后，单击 **“确认导入”**；
8. 系统事务化写入，任一行失败均不会创建项目；
9. 导入不会覆盖已有项目。

### 6.4 管理项目负责人和生命周期

在项目详情中，PMO可以：

- 编辑项目基本信息；
- 从账号目录调整项目负责人；
- 执行结项、归档和恢复在建。

结项前系统检查：

1. 未完成适用节点；
2. 开放风险；
3. 未完成措施；
4. 待审批基线变更。

存在未闭环事项时，只有明确勾选例外结项并填写至少10个字符的原因后才能结项。结项或归档后项目只读，并退出催报、健康重算和快照完整率统计。

### 6.5 处理周报质量和通知

入口：**PMO管理 → 快照锁定**。

重点检查：

- 本周正式周报提交率；
- 缺报项目；
- 申报值与计算值相差超过5个百分点的项目；
- 红色项目；
- 待审批基线变更。

可执行：

- 单项目催报；
- 批量催报缺报项目；
- 单项目或批量升级红灯项目；
- 进入项目详情核验异常。

系统按项目、事件和周期进行通知去重，避免重复发送。

### 6.6 锁定和重新打开快照

系统默认每周五17:00自动锁数。PMO也可在检查通过后提前手动锁定。

#### 锁定

1. 确认周报完整率和异常队列；
2. 单击 **“锁定为Vn”**；
3. 锁定后管理大屏切换到最新快照；
4. 历史版本永久保留，可导出JSON快照。

#### 重新打开

1. 在已锁定快照上单击 **“重新打开”**；
2. 填写重新打开原因；
3. 通知相关项目经理完成修订；
4. 再次核验后手动锁定；
5. 系统生成新的快照版本，旧版本不被覆盖。

### 6.7 审批基线变更

入口：**PMO管理 → 基线变更**。

1. 选择待审批申请；
2. 核对原日期、新日期和偏差天数；
3. 审查变更原因和影响评估；
4. 选择：
   - **批准并生成Vn**：升级当前批准基线；
   - **驳回申请**：填写驳回原因后退回。
5. 审批结果自动通知申请人并写入审计。

### 6.8 管理标准节点模板

入口：**PMO管理 → 节点模板**。

可维护：

- 节点编码；
- 节点名称和顺序；
- 默认权重；
- 关键节点标识；
- 启停状态；
- 统一口径说明。

发布要求：

1. 启用节点权重合计必须为100%；
2. 发布后影响后续新建项目；
3. 现有项目的批准基线不会被直接覆盖。

自定义节点候选池可将高频自定义节点提升为标准节点草稿。提升后默认零权重、未启用；同步到其他项目时默认“不适用”，避免改变既有进度口径。

### 6.9 发布预警与评分规则

入口：**PMO管理 → 预警规则**。

可配置：

- 普通、关键节点黄红阈值；
- 项目绿黄分数阈值；
- 进度偏差扣分；
- 节点、风险、措施和缺报扣分；
- 各分类扣分封顶；
- 一票否决条件。

发布后：

1. 生成不可覆盖的新规则版本；
2. 自动重算全部在建项目；
3. 周度快照固化当期规则版本；
4. 历史版本可查询。

### 6.10 管理资源池和冲突

入口：**资源计划**。

PMO可以：

- 新增、编辑、启停人员、团队、供应商和环境资源；
- 配置每周容量；
- 新建全部项目的资源分配；
- 确认项目经理提交的计划分配；
- 处理超过85%的满载预警和超过100%的超配冲突；
- 导出容量报表。

确认超配资源分配时必须填写保留超配的原因。

### 6.11 查看系统管理信息

PMO可进入 **“用户与权限”** 查看：

- 用户、角色、启停状态和负责项目数量；
- 当前密码复杂度策略；
- 全量操作审计；
- 通知渠道和最近投递记录。

PMO不能创建、停用账号、调整角色、重置密码或修改密码策略；可以对失败的外部投递执行重试。

## 7. 系统管理员使用手册

### 7.1 角色目标

系统管理员拥有PMO全部业务权限，并负责账号安全、权限边界、密码策略和外部通知渠道。

### 7.2 预置用户账号

入口：**用户与权限 → 预置账号**。

1. 填写用户真实姓名；
2. 填写登录邮箱；
3. 选择角色：
   - 管理层只读；
   - 项目经理；
   - PMO；
   - 系统管理员。
4. 设置符合当前策略的初始密码；
5. 确认预置；
6. 通过安全渠道将初始密码交给用户。

### 7.3 调整角色和账号状态

在“用户与角色”列表中：

- 直接选择新角色完成角色调整；
- 单击账号状态按钮执行启用或停用。

系统保护规则：

1. 管理员不能在当前页面停用或降级自己的账号；
2. 仍负责项目的项目经理不能停用或更改角色；
3. 应先由PMO或管理员将其负责项目移交给其他已启用项目经理。

### 7.4 重置用户密码

1. 在目标用户行单击 **“重置密码”** 或 **“设置密码”**；
2. 输入新密码并再次确认；
3. 新密码必须满足当前复杂度策略；
4. 提交后，目标用户原有登录会话立即失效；
5. 通知用户使用新密码重新登录。

管理员修改自己的密码时，应使用右上角头像菜单中的 **“修改密码”**。

### 7.5 配置密码复杂度

入口：**用户与权限 → 密码复杂度策略**。

可配置：

- 最小密码长度：8–64位；
- 是否必须含字母；
- 是否必须含大写字母；
- 是否必须含小写字母；
- 是否必须含数字；
- 是否必须含特殊字符。

单击 **“保存并立即生效”** 后，新策略约束后续账号创建、个人修改密码和管理员重置密码；不会强制迁移已有密码。

### 7.6 配置外部通知渠道

入口：**用户与权限 → 外部消息渠道**。

支持：

- 企业微信机器人；
- 钉钉机器人；
- 通用Webhook；
- 电子邮件。

配置步骤：

1. 单击 **“新增渠道”**；
2. 填写渠道名称；
3. 选择渠道类型；
4. Webhook渠道填写HTTPS地址；邮件渠道填写收件人；
5. 选择订阅事件：
   - 周报催报；
   - 红灯升级。
6. 选择是否立即启用；
7. 保存后执行测试；
8. 在投递记录中查看发送状态、失败原因和重试次数。

注意：

- 最多20个邮件收件人；
- 邮件目标地址需满足Cloudflare Email Routing验证要求；
- 完整Webhook密钥和邮件收件人不在页面回显；
- 失败投递按5分钟、30分钟、2小时退避重试；
- 站内通知始终作为兜底渠道。

### 7.7 查看操作审计

系统管理页面展示最近全量关键操作，包括：

- 用户创建、角色调整、启停和密码重置；
- 密码策略更新；
- 项目、节点、周报、风险和措施变更；
- 基线申请、批准或驳回；
- 快照锁定和重新打开；
- 模板和规则发布；
- 通知渠道变更、测试和投递重试。

审计时间统一按 UTC+8 展示。项目详情的“操作审计”标签仅展示该项目相关记录。

## 8. 关键规则速查

### 8.1 默认节点灯色

| 节点类型 | 绿色 | 黄色 | 红色 |
|---|---|---|---|
| 普通节点 | 偏差≤3天 | 偏差4–7天 | 偏差≥8天 |
| 关键节点 | 无延期 | 延期1–3天 | 延期≥4天 |

- 未到期节点使用预测完成日预警；
- 已完成节点使用实际完成日度量；
- 已过计划完成日且未完成的节点直接红色；
- 具体阈值以PMO当前发布的规则版本为准。

### 8.2 项目健康度

项目健康度基础分为100，综合考虑：

- 计划与实际进度偏差；
- 普通和关键节点黄红灯；
- 开放中高风险；
- 逾期措施；
- 本周缺报和连续缺报。

默认分级：

- 85–100：绿色；
- 70–84：黄色；
- 低于70：红色。

关键节点红色、高风险关联措施逾期或连续两个周期缺报可直接触发红色一票否决。项目详情会展示扣分项和否决原因。

### 8.3 自动化节奏

- 周三起：生成周报提醒；
- 周五17:00：自动锁定周度快照；
- 锁定后：生成缺报逾期通知和红灯升级；
- 每日：按上海时区重算在建项目健康度；
- 失败的外部消息：按退避计划自动重试。

## 9. 常见问题

### 9.1 为什么我看不到“周度填报”？

管理层角色为只读角色，不显示周度填报。项目经理、PMO和系统管理员可进入周度填报。

### 9.2 为什么项目经理不能修改某个项目？

可能原因：

- 当前账号不是该项目负责人；
- 项目已结项或已归档；
- 本周期快照已锁定；
- 账号角色或启停状态已调整。

### 9.3 为什么计划完成日期不能直接编辑？

计划完成日期属于批准基线。为保证可追溯，必须通过“申请基线变更 → PMO审批”调整。

### 9.4 为什么周报不能正式提交？

检查：

- 是否选择了适用节点；
- 是否填写本周进展或偏差原因；
- 红黄节点是否完整填写措施、责任人、恢复日期和具体行动；
- 项目是否仍为在建；
- 当前周期是否已锁定。

### 9.5 为什么账号不能停用或改变角色？

该账号可能仍负责项目。先将相关项目移交给其他已启用项目经理，再调整账号。

### 9.6 为什么大屏数据与工作台刚修改的数据不一致？

大屏默认使用最新已锁定快照，工作台展示当前数据。待PMO完成下一次锁数后，大屏切换到新口径。

### 9.7 时间为什么与数据库中的UTC时间不同？

数据库可保存UTC时间，页面统一转换为 UTC+8（Asia/Shanghai）展示。计划日期属于业务日期，不执行时区换日。

### 9.8 快照锁定后发现错误怎么办？

联系PMO说明原因，由PMO重新打开快照；完成修订后重新锁定，系统生成新版本并保留原版本。
